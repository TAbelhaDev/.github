## The stack

- **Web apps** — SvelteKit 2 + Svelte 5, Tailwind v4, Cloudflare Workers, shared
  theme via [`tabelawebui`](https://github.com/TabelaDev/tabelawebui)
  (Catppuccin + "reading someone's source file").
- **TUIs** — Go + Bubble Tea, shared theme via [`tabelatuiui`](https://github.com/TabelaDev/tabelatuiui).
